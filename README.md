# Codex Engineering Guidelines

A Codex-native set of engineering principles and task-focused skills for working safely in long-lived software systems.

This repository adapts the ideas behind [Karpathy-Inspired Claude Code Guidelines](https://github.com/multica-ai/andrej-karpathy-skills) to Codex's `AGENTS.md` and `SKILL.md` conventions. It is an independent adaptation, not an official Andrej Karpathy or OpenAI project.

> Initial documentation and skills are proposed on a feature branch; see the open pull request.

## Scope

The guidance emphasizes explicit contracts and assumptions, conceptual integrity, dependency-aware change scope, and verifiable outcomes. It does not grant new Codex capabilities, enforce security boundaries, or replace project-specific architectural decisions.

## Attribution

Inspired by the four principles documented in [multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills): thinking before coding, simplicity, surgical changes, and goal-driven execution. Wording and structure here are independently adapted for Codex and longer-lived systems.
