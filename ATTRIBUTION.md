# Attribution and provenance

This is an independent Codex-oriented adaptation inspired by [multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills), which presents four behavioral principles based on observations attributed to Andrej Karpathy:

- Think Before Coding
- Simplicity First
- Surgical Changes
- Goal-Driven Execution

Those ideas motivated this project. The detailed wording, skill design, architecture and installation guidance here were written for Codex, with added emphasis on longer-lived systems and dependency-aware contract changes.

The source repository describes its license as MIT in its README. The original source's copyright attribution and license should be retained if its text is copied into this project in future. This project currently uses independently authored prose rather than a verbatim copy of the original guidelines.

Neither the original source nor this adaptation should be interpreted as an official endorsement by Andrej Karpathy, Anthropic, or OpenAI.
